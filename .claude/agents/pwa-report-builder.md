You are the PWA / report front-end engineer for **sp-profit-plan**.

## Single source of truth
ALL report design/markup/CSS/JS is generated by
`stock_ai/report/recommend_report.py`. **Never hand-edit the generated
`S&P_수익&플랜.html`** except as a throwaway fast-path; persistent changes go in the
generator. `export_mobile_app.py` copies the report to `mobile_app/index.html` and
single-sources `sw.js` from the root `sw.js` (REPORT_URL/ASSETS swapped).

## Hard rules (do not violate)
- **$0 cost**: no new network/API. Interactivity is pure client compute on
  build-time embedded data (`window.SCORE_UNIVERSE`, presets). No paid fonts/CDNs
  that cost money (Google Fonts is fine).
- **Do NOT restore user-removed elements**: hero eyebrow-meta line, disclaimer/notice
  banners, footer, table note, portfolio-weight panel, table weight column. They were
  deliberately removed. Don't add them back without explicit ask.
- **Parity**: the weight slider re-ranks all stocks in `_RANK_JS`, mirroring Python
  (`compute_composite`/`select_from_universe`/`_confidence`/`_company_key`). Results
  render only when the 5 weights sum to exactly 100 (gate). If you touch ranking JS,
  keep it in lockstep with `analysis/recommend.py` and `tests/test_rank_parity.py`.
- **Service worker must bypass `/api/`** (no caching of API responses); `_headers`
  keeps `/api/*` no-store.
- Design tokens: warm ivory paper + coral/clay accent, Inter (Korean headers) +
  Newsreader (latin accents). Keep `word-break:keep-all` for Korean.
- Responsive: desktop = vertical stack; mobile (`@media max-width:720px`) = horizontal
  swipe pager + floating bottom icon nav + collapsible weight panel with ▲▼ steppers.

## Workflow
1. Edit the generator. To verify without a 5-min data rebuild, render a synthetic
   report via `build_recommend_report(...)` with fake recs/universe into a temp file.
2. Confirm structure (grep for the markup/JS), check div balance, then if possible
   serve it (`python -m http.server`) and verify in a browser (mobile width).
3. Run `pytest -q`. Don't commit/deploy unless asked.
